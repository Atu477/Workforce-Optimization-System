# Workforce Optimization System

The Workforce Optimization System is a web-based application designed to help small and medium-sized manufacturing industries manage their workforce, employee skills, attendance, and daily production activities efficiently.

## 📌 Project Overview

Managing manpower and employee skills manually can be time-consuming and may lead to errors. This system provides a centralized platform where administrators, HR personnel, and supervisors can manage workforce-related information and monitor production activities.

The system helps organizations assign suitable workers to different workstations based on their skills and availability.

## 🎯 Objectives

- Manage employee and workforce information.
- Track employee attendance using QR-based attendance.
- Maintain employee skill information.
- Provide a skill matrix for workforce analysis.
- Manage station-wise manpower allocation.
- Monitor workforce availability.
- Record 4M changes.
- Maintain checksheets and tool-life information.
- Monitor important production KPIs.
- Provide separate dashboards for Admin, HR, and Supervisors.
- Reduce manual workforce management.
- Improve workforce planning and productivity.

## 🚀 Main Features

### 👨‍💼 Admin Dashboard
- Manage users and employees.
- Monitor overall workforce information.
- Manage system data and settings.

### 👩‍💼 HR Dashboard
- Employee management.
- Attendance monitoring.
- Skill management.
- Workforce reports.

### 👷 Supervisor Dashboard
- Station-wise manpower allocation.
- Employee skill verification.
- Attendance monitoring.
- Production-related information.
- KPI monitoring.

### 📱 QR Attendance
Employees can mark attendance using a QR-based attendance system.

### 🧠 Skill Matrix
The skill matrix helps identify employee skills and determine which workers are suitable for particular workstations.

### 🏭 Station-wise Manpower
Supervisors can view and manage manpower assigned to different production stations.

### 🔄 4M Change Management
The system helps record changes related to:

- Man
- Machine
- Material
- Method

### ✅ Checksheet Management
Production checksheets can be maintained digitally for easier monitoring and record keeping.

### 🔧 Tool Life Management
The system provides information for monitoring tool usage and tool life.

### 📊 KPI Dashboard
Important workforce and production indicators can be monitored through dashboards.
